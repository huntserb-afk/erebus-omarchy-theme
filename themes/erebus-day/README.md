# EREBUS

**Primordial Darkness — an Omarchy theme inspired by Erebus, the ancient Greek personification of darkness.**

EREBUS is built around the idea of primordial darkness rather than the usual neon "hacker" aesthetic.

### Design

* Obsidian-black backgrounds
* Ash and weathered-stone text
* Deep crimson accents
* Sharp, minimal borders
* Subtle shadows
* Ancient-underworld atmosphere
* Minimal purple and neon colors

### Philosophy

> Darkness does not need to glow.

EREBUS is meant to feel like the ancient underworld: dark, restrained, cold, and occasionally illuminated by crimson.

## Installation

Copy the theme into your Omarchy themes directory:

```bash
cp -r EREBUS ~/.config/omarchy/themes/erebus
```

Then select **EREBUS** from the Omarchy theme selector.
